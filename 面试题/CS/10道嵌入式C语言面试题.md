# 10道嵌入式C语言面试题

## 第1题：if语句赋值分析

分析下面的C代码，它的运行结果可能是：

```c
#include <stdio.h>
int main(void)
{
    int i = 0;
    if (i = 1)
        printf("i > 0\n");
    else if (i = 0)
        printf ("i = 0\n");
    else
        printf ("i < 0\n");
    return 0;
}
A i > 0
B i = 0
C i < 0
D 使用不同的编译器编译运行，结果可能不一样
```

**答案：A**

**解析**：本题考察if语句中的赋值运算符`=`与比较运算符`==`的区别。

`i = 1`是赋值表达式，将1赋值给i，并返回赋值的结果（即1）。由于1为真，所以执行第一个printf语句，输出`i > 0`。

注意：即使i的初始值为0，`if(i = 1)`也会将i设为1，然后条件为真。许多新手会把`i = 1`误认为是`i == 1`，这是常见的错误。

## 第2题：变量声明与定义

关于变量的声明和定义，下面说法错误的是：

```
A 一个变量可以进行多次声明
B 一个变量只能声明一次
C 一个变量只能定义一次
D 变量的定义会给这个变量分配内存，而声明不会
```

**答案：B**

**解析**：变量的声明和定义是不同的概念：

- **声明**：告诉编译器这个变量存在，不分配内存。可以用`extern`关键字声明。
- **定义**：分配内存空间，每个变量只能定义一次。

对于`extern`声明的变量，可以多次声明，但只能定义一次。例如：
```c
extern int i;  // 声明
int i = 10;    // 定义（也可作为声明）
```

## 第3题：可能是定义的声明

下面关于变量的声明中，有可能是定义语句的是：

```
A extern int i;
B extern int a[20];
C extern struct student stu;
D int i;
```

**答案：D**

**解析**：

- `extern int i;` — 这是**声明**，`extern`表示变量在别处定义
- `extern int a[20];` — 这也是**声明**
- `extern struct student stu;` — 这还是**声明**

只有`int i;`既可以是声明也可以是定义（取决于上下文）。当没有`extern`修饰且不在函数内部时，这是定义。

## 第4题：signed与unsigned比较

阅读下面的代码，可能的运行结果是：

```c
#include <stdio.h>
int main (void) {
    int a = -3;
    unsigned int b = 3;
    if (a < b)
        printf("a < b\n");
    else
        printf("a > b\n");
    return 0;
}
A a < b
B a > b
C 在不同的编译器下运行结果可能不一样
```

**答案：B**

**解析**：本题考察signed与unsigned混合运算时的类型转换规则。

当`int a`与`unsigned int b`进行比较时，`int`会被隐式转换为`unsigned int`。

-3的补码表示（在32位系统中）为`0xFFFFFFFD`，转换为unsigned int后变成了很大的正数`4294967293`，远大于3。

因此`a > b`成立，输出`a > b`。

## 第5题：数组指针赋值

关于数组指针的使用，下面哪一条赋值语句可能会有问题？

```c
#include <stdio.h>
int main (void)
{
    int a[5] = {1,2,3,4,5};
    int *p = NULL;
    return 0;
}
A p = a;
B p = &a[4];
C p = &a;
D p = &a[0];
```

**答案：C**

**解析**：

| 语句 | 类型 | 说明 |
|------|------|------|
| `p = a;` | `int*` | a作为数组名，退化为指向首元素的指针 |
| `p = &a[4];` | `int*` | 指向第5个元素 |
| `p = &a;` | `int (*)[5]` | `&a`是指向整个数组的指针，类型是`int (*)[5]`，赋给`int*`会警告/错误 |
| `p = &a[0];` | `int*` | 与`p = a`等价 |

`&a`的类型是`int (*)[5]`（数组指针），不能直接赋给`int*`类型的变量。

## 第6题：全局变量extern分析

在sub.c和main.c中有如下程序代码，使用gcc编译运行，结果是？

```c
// sub.c
int i;
void print_val(void)
{
    printf ("%d\n", i);
}
// main.c
extern void print_val(void);
int i = 10;
int main(void)
{
    printf("%d\n", i);
    print_val();
    return 0;
}
```

**答案：输出 10 0**

**解析**：

- main.c中定义了全局变量`i = 10`
- sub.c中也定义了全局变量`i`（默认初始化为0）
- `extern void print_val(void);`只是声明print_val函数，不影响i的作用域

main.c中的`printf("%d\n", i)`输出10；调用print_val()时，访问的是sub.c中定义的i（值为0）。

## 第7题：sizeof操作符分析

在main.c和sub.c中分别有如下代码，编译运行，结果是？

```c
// sub.c
char i;
void print(void)
{
    printf("%d", sizeof(i));
}
// main.c
extern void print(void);
int i;
int main(void)
{
    printf("%d", sizeof(i));
    print();
    return 0;
}
```

**答案：输出 4 **

**解析**：

- main.c中的`i`是`int`类型，`sizeof(int)` = 4字节
- sub.c中的`i`是`char`类型，`sizeof(char)` = 1字节

注意：全局变量同名但类型不同，它们是不同作用域的变量，不会冲突。

## 第8题：函数与全局变量分析

编译运行下面的main.c和sub.c，可能的运行结果是：

```c
// sub.c
int i = 10;
void print(void)
{
    printf("%d", i);
}
// main.c
int i = 20;
extern void print(void);
int main(void)
{
    printf("%d", i);
    print();
    return 0;
}
```

**答案：D（编译错误）**

**解析**：

在链接阶段会出现**重复定义**错误（multiple definition of `i`）。

虽然`i`在两个文件中都是`extern`（默认）的，且分别初始化为10和20，但链接器不知道应该使用哪个定义，因此报错。

**解决方法**：在一个文件中使用`static`限制作用域：
```c
// main.c
static int i = 20;  // 只在main.c中可见
```

## 第9题：数组下标访问

在下面的代码中，我们定义了一个整型数组a[5]，如果想把数组元素a[2]的值打印出来，下面那条语句可能会打印错误？

```c
#include <stdio.h>
int main(void)
{
    int a[5] = {1,2,3,4,5};
    int *p = a;
    return 0;
}
A printf("%d\n", *(p+2));
B printf("%d\n", *(&a+2));
C printf("%d\n", 2[p]);
D printf("%d\n", 2[a]);
```

**答案：B**

**解析**：

| 语句 | 结果 | 说明 |
|------|------|------|
| `*(p+2)` | 3 | 正确，指针运算 |
| `*(&a+2)` | 错误 | `&a`是`int (*)[5]`类型，`+2`跳过整个数组，不是访问a[2] |
| `2[p]` | 3 | 正确，C语言中`a[b]`等价于`*(a+b)` |
| `2[a]` | 3 | 正确，与上面等价 |

`&a`是指向数组的指针，加2跳过的是`2*sizeof(a)`字节，不是数组元素。

## 第10题：变量作用域分析

运行下面的程序代码，运行的结果是：

```c
#include <stdio.h>

int main(void) {
    int i = 5;
    printf("%d ", i);
    {
        int i;  // 新声明的局部变量，隐藏外层i
        i = 10;
        printf("%d ", i);
    }
    printf("%d ", i);  // 访问外层i
    return 0;
}
A 5 10 10
B 5 5 5
C 5 10 5
D 10 10 10
```

**答案：C（输出 5 10 5）**

**解析**：

本题考察C语言中的作用域规则：

1. 初始`i = 5`，输出第一个`5`
2. 块内重新声明了`int i`（与外层i是不同的变量），覆盖了外层i
3. 块内`i = 10`，输出`10`
4. 块结束后，内层i被销毁，外层i仍然是5
5. 输出最后一个`5`

注意：内层声明的`int i`没有初始化就直接赋值，局部变量未初始化是未定义行为（垃圾值），但这里在赋值之后才使用，所以输出正确。

|------|--------|--------|
| 1 | 赋值vs比较 | `i=1`是赋值不是比较 |
| 2 | 声明vs定义 | 可以多次声明，只能一次定义 |
| 3 | extern声明 | extern声明不是定义 |
| 4 | signed/unsigned | 混合运算时signed转unsigned |
| 5 | 数组指针类型 | `&a`是数组指针不是元素指针 |
| 6 | 全局变量作用域 | 不同文件全局变量各自独立 |
| 7 | sizeof操作符 | 不同类型变量sizeof不同 |
| 8 | 重复定义 | 多个文件全局变量同名会冲突 |
| 9 | 指针运算 | `&a+2`跳过的单位是整个数组 |
| 10 | 作用域规则 | 内层块可以隐藏外层变量 |
