# C语言数组

## 数组的本质：为什么需要数组？

在C语言中，**数组是一组相同数据类型元素的集合**，存储在**连续的内存空间**中。

-   **核心作用**：批量管理同类数据，避免重复定义单个变量。
    例如，存储50名学生的成绩时，用数组`int scores[50]`比定义50个独立变量更高效。
-   **物理特性**：数组元素在内存中**连续排列**，每个元素的地址可通过首地址计算得出。
    假设数组首地址为`0x1000`，每个元素占4字节（如`int`类型），则第3个元素`scores[2]`的地址为 `0x1000 + 2×4 = 0x1008`。

## 数组的声明与初始化：如何创建数组？

### 声明语法

```
数据类型 数组名[元素个数];
```

**元素个数必须是常量或常量表达式**（C99允许变长数组VLA，需注意作用域）。

**示例**：

```
int nums[5];       // 合法：元素个数为常量5
const int n = 10;
float arr[n];      // 合法（C99）：n是常量表达式
int m = 20;
char str[m];       // 非法（C99前），C99后作为VLA合法（需编译器支持）
```

### 初始化方式

**完全初始化**：显式指定所有元素的值。

```
int scores[5] = {85, 90, 78, 92, 88};  // 所有元素被初始化
```

**部分初始化**：未指定的元素自动初始化为0（数值型）或`'\0'`（字符型）。

```
int data[5] = {1, 2};  // 前两个元素为1、2，后三个为0
char ch_arr[3] = {'a', 'b'};  // 第三个元素为'\0'
```

**省略数组长度**：编译器自动根据初始化值的个数推断长度。

```
int ages[] = {18, 20, 22};  // 等价于 int ages[3] = {...}
char str[] = "Hello";       // 自动添加'\0'，实际长度为6
```

## 数组的访问：如何操作数组元素？

### 下标访问

通过`数组名[下标]`访问元素，下标从`0`开始。

**示例**：

```
int arr[3] = {10, 20, 30};
printf("%d", arr[1]);  // 输出20（等价于*(arr+1)）
```

**本质**：`arr[i]`等价于`*(arr + i)`，编译器通过指针运算实现访问。

### 数组与指针的深层关系

**数组名的双重含义**：

-   当数组名作为`sizeof`操作数时，返回整个数组的字节数（而非指针大小）。

    ```
    sizeof(arr);  // 结果为5×4=20（int数组）
    ```

-   当数组名作为`&`操作数时，返回数组指针（`int (*)[5]`类型）。

    ```
    int (*p_arr)[5] = &arr;  // 指向包含5个int的数组的指针
    ```

-   **大多数情况**：数组名会被隐式转换为指向首元素的指针（`int*`类型）。

    ```
    int arr[5];
    int *p = arr;  // 等价于 p = &arr[0]
    ```

## 多维数组：如何处理二维及以上数据？

### 二维数组的逻辑与物理结构

**逻辑结构**：类似表格（行×列），如`int matrix[2][3]`表示2行3列的数组。

**物理结构**：按**行优先顺序**连续存储。

```
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

内存中顺序为：`1 → 2 → 3 → 4 → 5 → 6`。

### 地址计算与指针类型

元素`matrix[i][j]`的地址为：`&matrix[0][0] + i×列数 + j`

**行指针与列指针**：

```
int (*row_ptr)[3] = matrix;  // 行指针，指向包含3个int的数组（即一行）
int *col_ptr = &matrix[0][0]; // 列指针，指向单个int元素
```

### 多维数组作为函数参数

必须指定除第一维外的所有维度，以便编译器计算地址。

```
void print_matrix(int arr[][3], int rows) {  // 正确声明，列数必须明确
    for (int i=0; i<rows; i++) {
        for (int j=0; j<3; j++) {
            printf("%d ", arr[i][j]);
        }
    }
}
```

## 数组作为函数参数：为什么会“退化”？

当数组作为函数参数时，会**退化为指向首元素的指针**，原数组的长度信息丢失。

**示例**：

```
void func(int arr[5]) {  // 等价于 void func(int *arr)
    printf("%d", sizeof(arr));  // 输出4或8（指针大小），而非20（数组大小）
}
```

**解决方案**：传递数组时需额外传递长度参数。

```
void process(int *arr, int len) {
    for (int i=0; i<len; i++) { /* 处理元素 */ }
}
```

## 字符数组与字符串：特殊的数组应用

### 字符串的本质

字符数组以`'\0'`（ASCII码0）作为结束标志，有效长度由`strlen`函数计算（不含`'\0'`）。

**初始化区别**：

```
char str1[] = "ABC";  // 长度为4（含'\0'）
char str2[3] = {'A', 'B', 'C'};  // 非字符串，无'\0'
```

### 字符串操作函数

| 函数名    | 功能                 | 注意事项                                  |
| :-------- | :------------------- | :---------------------------------------- |
| `strcpy`  | 复制字符串           | 目标数组需足够大，避免溢出                |
| `strcat`  | 拼接字符串           | 同上                                      |
| `strcmp`  | 比较字符串（字典序） | 返回值：<0（小于），0（等于），>0（大于） |
| `sprintf` | 格式化输出到字符数组 | 类似`printf`，结果写入数组                |

-   **安全函数替代**（C11标准）：使用`strcpy_s`、`strcat_s`等带`_s`后缀的函数，可检测缓冲区溢出。

## 常见错误与陷阱：如何避免数组“踩坑”？

### 数组越界访问

**后果**：访问非法内存，可能导致程序崩溃或数据篡改。

**示例**（危险！）：

```
int arr[5];
arr[5] = 100;  // 越界，下标最大为4
```

### 未初始化数组

未初始化的数组元素值为**不确定值**（垃圾值），使用前需初始化。

```
int values[3];
printf("%d", values[0]);  // 输出随机值，可能引发错误
```

### 变长数组（VLA）的限制

C99允许长度在运行时确定的数组（如`int arr[n]`，`n`为变量），但：
-   不能在文件作用域声明（只能在函数内）；
-   不能初始化（如`int arr[n] = {1,2,3};`非法）。

## 动态数组：突破静态数组的限制

静态数组长度固定，动态数组通过`malloc`/`realloc`在堆内存中动态分配空间。

### 基本操作示例

```
#include <stdlib.h>

// 创建动态数组
int* create_array(int size) {
    int *arr = (int*)malloc(size * sizeof(int));
    if (arr == NULL) { exit(EXIT_FAILURE); }  // 检查内存分配失败
    return arr;
}

// 扩容数组
int* resize_array(int *arr, int old_size, int new_size) {
    int *new_arr = (int*)realloc(arr, new_size * sizeof(int));
    return new_arr;  // 若成功，返回新地址；若失败，返回NULL且原数组不变
}

// 使用完毕后释放内存
void free_array(int *arr) {
    free(arr);
}
```

### 动态数组 vs 静态数组

| 特性         | 静态数组   | 动态数组            |
| :----------- | :--------- | :------------------ |
| 内存分配时机 | 编译时     | 运行时              |
| 长度可变     | 否         | 是（通过`realloc`） |
| 内存位置     | 栈或全局区 | 堆                  |

## 实战应用：数组的典型场景

1.  **排序与搜索**：
    -   排序：冒泡排序、快速排序等算法基于数组实现；
    -   搜索：有序数组可使用二分查找（时间复杂度`O(logn)`）。
2.  **矩阵运算**：二维数组表示矩阵，实现乘法、转置等操作。
3.  **稀疏数组优化**：仅存储非零元素的位置和值，减少内存占用（如棋盘游戏、科学计算）。
