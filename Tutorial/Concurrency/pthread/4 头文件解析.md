# 头文件解析

## `<pthread.h>` — 线程核心接口

### 数据类型定义

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| `pthread_t` | 线程标识符 | 标识一个线程，不应用 `==` 直接比较，应使用 `pthread_equal()` |
| `pthread_mutex_t` | 互斥锁类型 | 保护临界区资源 |
| `pthread_cond_t` | 条件变量类型 | 线程间条件等待与通知 |
| `pthread_rwlock_t` | 读写锁类型 | 多读单写场景 |
| `pthread_barrier_t` | 屏障类型 | 多线程同步点 |
| `pthread_attr_t` | 线程属性类型 | 创建线程时设置属性 |
| `pthread_mutexattr_t` | 互斥锁属性类型 | 设置互斥锁类型（普通/递归/检错等） |
| `pthread_condattr_t` | 条件变量属性类型 | 设置条件变量属性 |
| `pthread_key_t` | 线程特定数据键 | 线程局部存储 |

### 核心函数

#### 线程创建与结束

```c
// 创建线程
int pthread_create(pthread_t *thread,
                   const pthread_attr_t *attr,
                   void *(*start_routine)(void *),
                   void *arg);

// 等待线程结束
int pthread_join(pthread_t thread, void **retval);

// 分离线程（结束后自动回收资源）
int pthread_detach(pthread_t thread);

// 线程主动退出
void pthread_exit(void *retval);

// 获取当前线程ID
pthread_t pthread_self(void);

// 比较两个线程ID是否相等（因 pthread_t 可能是结构体）
int pthread_equal(pthread_t t1, pthread_t t2);
```

#### 线程取消

```c
// 请求取消指定线程
int pthread_cancel(pthread_t thread);

// 设置取消状态（启用/禁用取消）
int pthread_setcancelstate(int state, int *oldstate);

// 设置取消类型（延迟取消/异步取消）
int pthread_setcanceltype(int type, int *oldtype);

// 建立取消点
void pthread_testcancel(void);
```

#### 互斥锁操作

```c
// 初始化互斥锁
int pthread_mutex_init(pthread_mutex_t *mutex,
                       const pthread_mutexattr_t *attr);

// 静态初始化（默认属性）
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

// 加锁（阻塞）
int pthread_mutex_lock(pthread_mutex_t *mutex);

// 尝试加锁（非阻塞）
int pthread_mutex_trylock(pthread_mutex_t *mutex);

// 限时加锁
int pthread_mutex_timedlock(pthread_mutex_t *mutex,
                            const struct timespec *abstime);

// 解锁
int pthread_mutex_unlock(pthread_mutex_t *mutex);

// 销毁互斥锁
int pthread_mutex_destroy(pthread_mutex_t *mutex);
```

#### 条件变量操作

```c
// 初始化条件变量
int pthread_cond_init(pthread_cond_t *cond,
                      const pthread_condattr_t *attr);

// 静态初始化
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;

// 等待条件（自动释放锁并阻塞，被唤醒后重新获取锁）
int pthread_cond_wait(pthread_cond_t *cond,
                      pthread_mutex_t *mutex);

// 限时等待
int pthread_cond_timedwait(pthread_cond_t *cond,
                           pthread_mutex_t *mutex,
                           const struct timespec *abstime);

// 唤醒一个等待线程
int pthread_cond_signal(pthread_cond_t *cond);

// 唤醒所有等待线程
int pthread_cond_broadcast(pthread_cond_t *cond);

// 销毁条件变量
int pthread_cond_destroy(pthread_cond_t *cond);
```

#### 读写锁操作

```c
// 初始化读写锁
int pthread_rwlock_init(pthread_rwlock_t *rwlock,
                        const pthread_rwlockattr_t *attr);

// 读锁定（共享锁，多个读线程可同时持有）
int pthread_rwlock_rdlock(pthread_rwlock_t *rwlock);

// 写锁定（排他锁，独占访问）
int pthread_rwlock_wrlock(pthread_rwlock_t *rwlock);

// 尝试读/写锁定（非阻塞）
int pthread_rwlock_tryrdlock(pthread_rwlock_t *rwlock);
int pthread_rwlock_trywrlock(pthread_rwlock_t *rwlock);

// 解锁
int pthread_rwlock_unlock(pthread_rwlock_t *rwlock);

// 销毁
int pthread_rwlock_destroy(pthread_rwlock_t *rwlock);
```

#### 屏障操作

```c
// 初始化屏障
int pthread_barrier_init(pthread_barrier_t *barrier,
                         const pthread_barrierattr_t *attr,
                         unsigned int count);

// 等待屏障（到达 count 个线程后一起继续）
int pthread_barrier_wait(pthread_barrier_t *barrier);

// 销毁屏障
int pthread_barrier_destroy(pthread_barrier_t *barrier);
```

#### 线程局部存储（TLS）

```c
// 创建线程特定数据键
int pthread_key_create(pthread_key_t *key, void (*destructor)(void *));

// 删除键
int pthread_key_delete(pthread_key_t key);

// 设置线程特定数据
int pthread_setspecific(pthread_key_t key, const void *value);

// 获取线程特定数据
void *pthread_getspecific(pthread_key_t key);
```

### 错误码

Pthread 函数返回 0 表示成功，非零表示错误。常见错误码：

| 错误码 | 值 | 含义 |
|--------|-----|------|
| `EINVAL` | 22 | 无效参数 |
| `EBUSY` | 16 | 资源忙（如 trylock 时锁已被持有） |
| `EAGAIN` | 11 | 资源暂时不可用（如超出线程数限制） |
| `ESRCH` | 3 | 无此线程 |
| `EDEADLK` | 35 | 死锁（如递归加锁非递归锁） |
| `EPERM` | 1 | 权限不足 |
| `ETIMEDOUT` | 110 | 超时 |

## `<sched.h>` — 线程调度

```c
// 设置调度策略和参数
int sched_setscheduler(pid_t pid, int policy, const struct sched_param *param);

// 获取调度策略
int sched_getscheduler(pid_t pid);

// 获取优先级范围
int sched_get_priority_max(int policy);
int sched_get_priority_min(int policy);

// 让出CPU
int sched_yield(void);
```

### 调度策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| `SCHED_OTHER` | 普通分时调度（默认） | 普通应用 |
| `SCHED_FIFO` | 实时先进先出 | 硬实时任务 |
| `SCHED_RR` | 实时时间片轮转 | 软实时任务 |

## `<semaphore.h>` — 信号量

```c
// 初始化未命名信号量
int sem_init(sem_t *sem, int pshared, unsigned int value);

// 销毁信号量
int sem_destroy(sem_t *sem);

// P操作（等待）：信号量值减1，若为0则阻塞
int sem_wait(sem_t *sem);

// 尝试P操作（非阻塞）
int sem_trywait(sem_t *sem);

// 限时P操作
int sem_timedwait(sem_t *sem, const struct timespec *abstime);

// V操作（发布）：信号量值加1，唤醒等待线程
int sem_post(sem_t *sem);

// 获取当前信号量值
int sem_getvalue(sem_t *sem, int *sval);
```

> **注意**：`sem_init` 初始化的信号量用于线程间同步；进程间同步需使用命名信号量（`sem_open`）。

## `<errno.h>` — 错误处理

Pthread 函数通常返回错误码而不是设置 `errno`，但某些底层操作仍会使用 `errno`。建议：

```c
int ret = pthread_mutex_lock(&mutex);
if (ret != 0) {
    // 使用 strerror 获取错误描述
    fprintf(stderr, "Lock failed: %s\n", strerror(ret));
    // 或使用 perror（注意：perror 读取的是 errno，不是 ret）
    errno = ret;  // 先赋值给 errno
    perror("pthread_mutex_lock");
}
```
