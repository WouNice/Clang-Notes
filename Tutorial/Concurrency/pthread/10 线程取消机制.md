# 线程取消机制

## 基本概念

线程取消是一种请求机制，一个线程可以请求另一个线程终止执行。被请求的线程可以选择接受或忽略该请求。

```c
/**
 * @brief 向目标线程发送取消请求
 * @param thread 目标线程ID
 * @return 成功返回0，失败返回错误码
 * @note 仅发送请求，目标线程在取消点才会响应
 */
int pthread_cancel(pthread_t thread);
```

## 取消状态（Cancel State）

控制线程是否响应取消请求：

```c
/**
 * @brief 设置线程的取消状态
 * @param state     新状态：PTHREAD_CANCEL_ENABLE 或 PTHREAD_CANCEL_DISABLE
 * @param oldstate  输出参数，保存旧状态（可为NULL）
 * @return          成功返回0
 */
int pthread_setcancelstate(int state, int *oldstate);
```

| 状态 | 说明 |
|------|------|
| `PTHREAD_CANCEL_ENABLE` | 默认状态，线程会响应取消请求 |
| `PTHREAD_CANCEL_DISABLE` | 忽略取消请求，请求被挂起直到状态变为 ENABLE |

## 取消类型（Cancel Type）

控制线程何时响应取消请求：

```c
/**
 * @brief 设置线程的取消类型
 * @param type      新类型：PTHREAD_CANCEL_DEFERRED 或 PTHREAD_CANCEL_ASYNCHRONOUS
 * @param oldtype   输出参数，保存旧类型（可为NULL）
 * @return          成功返回0
 */
int pthread_setcanceltype(int type, int *oldtype);
```

| 类型 | 说明 |
|------|------|
| `PTHREAD_CANCEL_DEFERRED` | 默认类型，只在取消点响应取消 |
| `PTHREAD_CANCEL_ASYNCHRONOUS` | 随时可能响应取消（危险，很少使用）|

## 取消点（Cancellation Points）

延迟取消模式下，线程只在以下函数调用时检查取消请求：

### 标准取消点

```
文件操作：
  open(), close(), read(), write(), pread(), pwrite()

I/O 操作：
  printf(), scanf(), fprintf(), fscanf()

线程同步：
  pthread_join(), pthread_cond_wait(), pthread_cond_timedwait()
  pthread_barrier_wait(), pthread_testcancel()

睡眠等待：
  sleep(), usleep(), nanosleep(), clock_nanosleep()

信号操作：
  sigwait(), sigsuspend(), pause()

消息队列：
  mq_receive(), mq_send(), mq_timedreceive(), mq_timedsend()

标准 I/O：
  fgets(), fputs(), fread(), fwrite()
```

### 显式取消点

```c
/**
 * @brief 显式建立取消点
 * @note 如果取消请求已挂起，立即响应
 */
void pthread_testcancel(void);
```

## 清理处理程序（Cleanup Handlers）

确保线程被取消时资源得到释放：

```c
/**
 * @brief 注册清理函数（栈结构，后注册的先执行）
 * @param routine   清理函数
 * @param arg       传递给清理函数的参数
 */
void pthread_cleanup_push(void (*routine)(void *), void *arg);

/**
 * @brief 弹出清理函数
 * @param execute   非0时执行清理函数，0时不执行
 */
void pthread_cleanup_pop(int execute);
```

> **注意**：`pthread_cleanup_push` 和 `pthread_cleanup_pop` 必须成对出现，且在同一作用域内。

## 完整示例：安全的线程取消

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

static pthread_t worker_thread;
static volatile int task_running = 0;

// 清理函数：关闭文件
void cleanup_close_file(void *arg)
{
    FILE *fp = (FILE *)arg;
    if (fp) {
        printf("Cleanup: closing file\n");
        fclose(fp);
    }
}

// 清理函数：释放内存
void cleanup_free_buffer(void *arg)
{
    void *buf = arg;
    if (buf) {
        printf("Cleanup: freeing buffer\n");
        free(buf);
    }
}

// 清理函数：释放锁
void cleanup_unlock_mutex(void *arg)
{
    pthread_mutex_t *mutex = (pthread_mutex_t *)arg;
    printf("Cleanup: unlocking mutex\n");
    pthread_mutex_unlock(mutex);
}

void *worker_function(void *arg)
{
    // 启用取消机制
    pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    pthread_setcanceltype(PTHREAD_CANCEL_DEFERRED, NULL);

    task_running = 1;

    // 打开文件
    FILE *fp = fopen("data.txt", "r");
    if (!fp) {
        perror("fopen");
        pthread_exit((void *)-1);
    }

    // 注册清理函数（栈结构，后注册的先执行）
    pthread_cleanup_push(cleanup_close_file, fp);

    // 分配缓冲区
    char *buffer = malloc(1024);
    if (!buffer) {
        pthread_cleanup_pop(1);  // 关闭文件
        pthread_exit((void *)-1);
    }
    pthread_cleanup_push(cleanup_free_buffer, buffer);

    printf("Worker: starting processing...\n");

    int line_count = 0;
    while (task_running) {
        // 显式取消点
        pthread_testcancel();

        if (fgets(buffer, 1024, fp) == NULL) {
            break;  // 文件读取完毕
        }

        line_count++;
        printf("Worker: processing line %d: %s", line_count, buffer);

        // 模拟处理时间
        sleep(1);
    }

    printf("Worker: processed %d lines\n", line_count);

    // 弹出清理函数（execute=1 表示执行）
    pthread_cleanup_pop(1);  // 释放缓冲区
    pthread_cleanup_pop(1);  // 关闭文件

    task_running = 0;
    pthread_exit((void *)0);
}

int main(void)
{
    int ret = pthread_create(&worker_thread, NULL, worker_function, NULL);
    if (ret != 0) {
        fprintf(stderr, "pthread_create failed: %s\n", strerror(ret));
        return 1;
    }

    // 主线程等待3秒后取消工作线程
    sleep(3);

    printf("Main: requesting thread cancellation...\n");
    ret = pthread_cancel(worker_thread);
    if (ret != 0) {
        fprintf(stderr, "pthread_cancel failed: %s\n", strerror(ret));
    }

    // 等待线程结束
    void *thread_result;
    ret = pthread_join(worker_thread, &thread_result);
    if (ret != 0) {
        fprintf(stderr, "pthread_join failed: %s\n", strerror(ret));
    }

    // 检查线程是否被取消
    if (thread_result == PTHREAD_CANCELED) {
        printf("Main: thread was cancelled\n");
    } else {
        printf("Main: thread exited with code %ld\n", (long)thread_result);
    }

    return 0;
}
```

## 编译与运行

```bash
# 编译
gcc -o cancel_example cancel_example.c -pthread

# 运行
./cancel_example
```

## 关键要点总结

| 要点 | 说明 |
|------|------|
| 取消是请求，不是命令 | `pthread_cancel` 只发送请求，目标线程可选择忽略 |
| 使用延迟取消 | `PTHREAD_CANCEL_DEFERRED` 更安全，只在取消点响应 |
| 避免异步取消 | `PTHREAD_CANCEL_ASYNCHRONOUS` 可能导致资源泄漏 |
| 注册清理函数 | 使用 `pthread_cleanup_push/pop` 确保资源释放 |
| 显式取消点 | 在长时间运行的循环中调用 `pthread_testcancel()` |
| 检查返回值 | `pthread_join` 的返回值可能是 `PTHREAD_CANCELED` |
| 禁用取消保护关键区 | 使用 `pthread_setcancelstate(PTHREAD_CANCEL_DISABLE, NULL)` |

## 常见错误

| 错误 | 后果 | 避免方法 |
|------|------|---------|
| 忘记注册清理函数 | 线程取消时资源泄漏 | 所有资源获取后立即注册清理函数 |
| 使用异步取消 | 随机位置被取消，状态不一致 | 始终使用延迟取消 |
| 在关键区不禁用取消 | 持有锁时被取消，导致死锁 | 获取锁前禁用取消，释放后启用 |
| 假设取消立即生效 | 线程可能继续运行一段时间 | 使用 `pthread_join` 等待确认 |
