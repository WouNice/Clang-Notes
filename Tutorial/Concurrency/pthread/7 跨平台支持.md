# 跨平台支持

## Pthread 的跨平台实现

### Windows 支持

Windows 原生不支持 POSIX 线程，但有多种兼容方案：

| 方案 | 说明 | 推荐度 |
|------|------|--------|
| **pthreads4w** (原 pthreads-win32) | 最成熟的 Windows Pthread 实现 | ⭐⭐⭐⭐⭐ |
| **winpthreads** (MinGW-w64) | MinGW 内置的 Pthread 实现 | ⭐⭐⭐⭐ |
| **C++11 std::thread** | 标准 C++ 线程库，跨平台 | ⭐⭐⭐⭐ |

### pthreads4w 使用

1. **下载**：https://sourceforge.net/projects/pthreads4w/
2. **编译安装**：
   ```bash
   nmake clean VC
   # 或
   cmake -G "Visual Studio 16 2019" -A x64 .
   cmake --build . --config Release
   ```
3. **项目配置**：
   - 包含目录：`pthreads4w/include`
   - 库目录：`pthreads4w/lib`
   - 链接库：`pthreadVC3.lib`（Release）或 `pthreadVC3d.lib`（Debug）

### 跨平台代码示例

```c
#include <stdio.h>

#ifdef _WIN32
    #include <windows.h>
    #include "pthread.h"  // pthreads4w 头文件
#else
    #include <pthread.h>
    #include <unistd.h>
#endif

// 跨平台睡眠函数
void cross_platform_sleep(int seconds)
{
#ifdef _WIN32
    Sleep(seconds * 1000);  // Windows: 毫秒
#else
    sleep(seconds);          // POSIX: 秒
#endif
}

void *thread_func(void *arg)
{
    printf("Thread running on %s\n",
#ifdef _WIN32
           "Windows"
#else
           "POSIX"
#endif
    );
    cross_platform_sleep(1);
    return NULL;
}

int main(void)
{
    pthread_t tid;
    pthread_create(&tid, NULL, thread_func, NULL);
    pthread_join(tid, NULL);
    printf("Done\n");
    return 0;
}
```

### CMake 跨平台配置

```cmake
cmake_minimum_required(VERSION 3.10)
project(CrossPlatformThreads)

# 查找线程库
set(THREADS_PREFER_PTHREAD_FLAG ON)
find_package(Threads REQUIRED)

add_executable(myapp main.c)

# Windows 下链接 pthreads4w
if(WIN32)
    # 设置 pthreads4w 路径
    set(PTHREADS4W_ROOT "${CMAKE_SOURCE_DIR}/third_party/pthreads4w")
    target_include_directories(myapp PRIVATE ${PTHREADS4W_ROOT}/include)
    target_link_directories(myapp PRIVATE ${PTHREADS4W_ROOT}/lib)
    target_link_libraries(myapp pthreadVC3)
else()
    target_link_libraries(myapp Threads::Threads)
endif()
```

### 平台差异注意事项

| 特性 | Linux | Windows (pthreads4w) | macOS |
|------|-------|---------------------|-------|
| `pthread_mutex_timedlock` | ✅ 原生支持 | ✅ 支持 | ✅ 支持 |
| `pthread_rwlock` | ✅ 原生支持 | ✅ 支持 | ✅ 支持 |
| `pthread_barrier` | ✅ 原生支持 | ✅ 支持 | ✅ 支持 |
| `pthread_spinlock` | ✅ 原生支持 | ✅ 支持 | ✅ 支持 |
| `pthread_setaffinity_np` | ✅ Linux 特有 | ❌ 不支持 | ❌ 不支持 |
| 实时调度策略 | ✅ 完整支持 | ⚠️ 有限支持 | ⚠️ 有限支持 |

> **建议**：编写跨平台代码时，避免使用 `_np`（non-portable）后缀的函数。
