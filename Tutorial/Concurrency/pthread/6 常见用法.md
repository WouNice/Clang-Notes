# 常见用法

## API 总览

```
线程生命周期
├── pthread_create        : 创建新线程
├── pthread_exit          : 线程主动退出
├── pthread_join          : 等待线程结束，获取返回值
├── pthread_detach        : 分离线程，自动回收资源
└── pthread_cancel        : 请求取消线程

线程属性
├── pthread_attr_init     : 初始化线程属性
├── pthread_attr_destroy  : 销毁线程属性
├── pthread_attr_setdetachstate : 设置分离状态
├── pthread_attr_getdetachstate : 获取分离状态
├── pthread_attr_setstacksize   : 设置栈大小
├── pthread_attr_getstacksize   : 获取栈大小
├── pthread_attr_setschedpolicy : 设置调度策略
└── pthread_attr_setschedparam  : 设置调度参数

互斥锁（Mutex）
├── pthread_mutex_init    : 初始化
├── pthread_mutex_lock    : 加锁（阻塞）
├── pthread_mutex_trylock : 尝试加锁（非阻塞）
├── pthread_mutex_timedlock : 限时加锁
├── pthread_mutex_unlock  : 解锁
├── pthread_mutex_destroy : 销毁
└── pthread_mutexattr_*   : 属性设置（类型、协议等）

条件变量（Condition Variable）
├── pthread_cond_init     : 初始化
├── pthread_cond_wait     : 等待（自动释放锁+阻塞）
├── pthread_cond_timedwait: 限时等待
├── pthread_cond_signal   : 唤醒一个等待线程
├── pthread_cond_broadcast: 唤醒所有等待线程
└── pthread_cond_destroy  : 销毁

读写锁（RWLock）
├── pthread_rwlock_init   : 初始化
├── pthread_rwlock_rdlock : 读锁定（共享）
├── pthread_rwlock_wrlock : 写锁定（排他）
├── pthread_rwlock_unlock : 解锁
└── pthread_rwlock_destroy: 销毁

屏障（Barrier）
├── pthread_barrier_init  : 初始化（指定等待线程数）
├── pthread_barrier_wait  : 等待到达屏障
└── pthread_barrier_destroy: 销毁

线程局部存储（TLS）
├── pthread_key_create    : 创建键
├── pthread_key_delete    : 删除键
├── pthread_setspecific   : 设置线程特定值
└── pthread_getspecific   : 获取线程特定值
```

## 线程的基本操作

### pthread_create

```c
/**
 * @brief 创建新线程
 * @param thread    输出参数，存储新线程ID
 * @param attr      线程属性，NULL表示默认属性
 * @param start_routine 线程入口函数
 * @param arg       传递给入口函数的参数
 * @return          成功返回0，失败返回错误码
 */
int pthread_create(pthread_t *thread,
                   const pthread_attr_t *attr,
                   void *(*start_routine)(void *),
                   void *arg);
```

**示例**：创建线程，每秒打印一次

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <pthread.h>

static pthread_t s_thread_id;
static volatile int s_thread_running = 0;

void *thread_fun(void *arg)
{
    s_thread_running = 1;
    while (s_thread_running) {
        printf("thread run...\n");
        sleep(1);
    }
    pthread_exit(NULL);
}

int main(void)
{
    int ret = pthread_create(&s_thread_id, NULL, thread_fun, NULL);
    if (ret != 0) {
        fprintf(stderr, "pthread_create failed: %s\n", strerror(ret));
        exit(EXIT_FAILURE);
    }

    sleep(3);
    s_thread_running = 0;  // 通知线程退出

    ret = pthread_join(s_thread_id, NULL);
    if (ret != 0) {
        fprintf(stderr, "pthread_join failed: %s\n", strerror(ret));
        exit(EXIT_FAILURE);
    }

    printf("Thread finished\n");
    return 0;
}
```

### pthread_join

```c
/**
 * @brief 等待线程结束
 * @param thread    目标线程ID
 * @param retval    输出参数，接收线程返回值（可为NULL）
 * @return          成功返回0，失败返回错误码
 */
int pthread_join(pthread_t thread, void **retval);
```

**示例**：获取线程返回值

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

void *compute_sum(void *arg)
{
    int n = *(int *)arg;
    static int result;  // 必须是静态或堆内存

    result = n * (n + 1) / 2;
    printf("Thread: sum(1..%d) = %d\n", n, result);

    pthread_exit(&result);  // 返回结果地址
}

int main(void)
{
    pthread_t tid;
    int num = 100;
    int *result = NULL;

    pthread_create(&tid, NULL, compute_sum, &num);
    pthread_join(tid, (void **)&result);

    if (result != NULL) {
        printf("Main: got result = %d\n", *result);
    }
    return 0;
}
```

### pthread_detach

```c
/**
 * @brief 分离线程，使其结束时自动回收资源
 * @param thread    目标线程ID
 * @return          成功返回0，失败返回错误码
 */
int pthread_detach(pthread_t thread);
```

**示例**：创建分离线程

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <pthread.h>

void *background_task(void *arg)
{
    int id = *(int *)arg;
    printf("Task %d started\n", id);
    sleep(2);
    printf("Task %d finished\n", id);
    return NULL;
}

int main(void)
{
    pthread_t tid;
    int task_id = 1;

    pthread_create(&tid, NULL, background_task, &task_id);
    pthread_detach(tid);  // 分离后无需join

    printf("Main: task detached, continuing...\n");
    sleep(3);  // 等待后台任务完成
    printf("Main: exiting\n");
    return 0;
}
```

### pthread_cancel

```c
/**
 * @brief 请求取消指定线程（发送取消请求）
 * @param thread    目标线程ID
 * @return          成功返回0，失败返回错误码
 * @note            仅发送请求，目标线程在取消点才会响应
 */
int pthread_cancel(pthread_t thread);
```

**示例**：取消正在执行的线程

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <pthread.h>

static volatile int s_cancelled = 0;

void *long_task(void *arg)
{
    // 启用取消机制
    pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    pthread_setcanceltype(PTHREAD_CANCEL_DEFERRED, NULL);

    for (int i = 0; i < 10; i++) {
        printf("Working... %d/10\n", i + 1);
        sleep(1);

        // pthread_testcancel() 是显式取消点
        pthread_testcancel();
    }

    printf("Task completed normally\n");
    return NULL;
}

int main(void)
{
    pthread_t tid;

    pthread_create(&tid, NULL, long_task, NULL);

    sleep(3);
    printf("Main: requesting cancel...\n");
    pthread_cancel(tid);

    void *result;
    pthread_join(tid, &result);

    if (result == PTHREAD_CANCELED) {
        printf("Thread was cancelled\n");
    }

    return 0;
}
```

### pthread_exit

```c
/**
 * @brief 终止当前线程
 * @param retval    线程返回值（可被 pthread_join 获取）
 * @note            调用后该线程立即结束，不影响其他线程
 */
void pthread_exit(void *retval);
```

**示例**：提前退出线程

```c
#include <stdio.h>
#include <pthread.h>

void *conditional_task(void *arg)
{
    int *value = (int *)arg;

    if (*value < 0) {
        printf("Invalid value, exiting thread\n");
        pthread_exit((void *)-1);  // 提前退出
    }

    printf("Processing value: %d\n", *value);
    // ... 处理逻辑 ...

    pthread_exit((void *)0);  // 正常退出
}

int main(void)
{
    pthread_t tid;
    int val = -5;
    void *result;

    pthread_create(&tid, NULL, conditional_task, &val);
    pthread_join(tid, &result);

    printf("Thread exited with: %ld\n", (long)result);
    return 0;
}
```

## 互斥锁（Mutex）

### 基本概念

互斥锁用于保护共享资源，确保同一时间只有一个线程访问临界区。

### 初始化与销毁

```c
// 动态初始化
pthread_mutex_t mutex;
int pthread_mutex_init(pthread_mutex_t *mutex,
                       const pthread_mutexattr_t *attr);

// 静态初始化（默认属性）
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

// 销毁
int pthread_mutex_destroy(pthread_mutex_t *mutex);
```

### 加锁与解锁

```c
// 阻塞加锁
int pthread_mutex_lock(pthread_mutex_t *mutex);

// 非阻塞加锁（失败立即返回EBUSY）
int pthread_mutex_trylock(pthread_mutex_t *mutex);

// 限时加锁
int pthread_mutex_timedlock(pthread_mutex_t *mutex,
                            const struct timespec *abstime);

// 解锁
int pthread_mutex_unlock(pthread_mutex_t *mutex);
```

### 互斥锁类型

```c
// 设置互斥锁类型
pthread_mutexattr_t attr;
pthread_mutexattr_init(&attr);
pthread_mutexattr_settype(&attr, PTHREAD_MUTEX_RECURSIVE);
pthread_mutex_init(&mutex, &attr);
pthread_mutexattr_destroy(&attr);
```

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| `PTHREAD_MUTEX_NORMAL` | 标准互斥锁，不检测死锁 | 简单场景 |
| `PTHREAD_MUTEX_RECURSIVE` | 递归锁，同一线程可多次加锁 | 递归函数中需要加锁 |
| `PTHREAD_MUTEX_ERRORCHECK` | 检错锁，重复加锁返回错误 | 调试阶段 |
| `PTHREAD_MUTEX_ADAPTIVE_NP` | 自适应锁，短暂自旋后阻塞 | 高并发短临界区 |

> **注意**：`_NP` 后缀表示 Non-Portable（非标准扩展），仅在 Linux 等特定平台可用。

### 完整示例：保护共享计数器

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

#define NUM_THREADS 5
#define INCREMENTS 100000

static int counter = 0;
static pthread_mutex_t counter_mutex = PTHREAD_MUTEX_INITIALIZER;

void *increment(void *arg)
{
    int id = *(int *)arg;

    for (int i = 0; i < INCREMENTS; i++) {
        pthread_mutex_lock(&counter_mutex);
        counter++;  // 临界区
        pthread_mutex_unlock(&counter_mutex);
    }

    printf("Thread %d finished\n", id);
    return NULL;
}

int main(void)
{
    pthread_t threads[NUM_THREADS];
    int thread_ids[NUM_THREADS];

    for (int i = 0; i < NUM_THREADS; i++) {
        thread_ids[i] = i;
        pthread_create(&threads[i], NULL, increment, &thread_ids[i]);
    }

    for (int i = 0; i < NUM_THREADS; i++) {
        pthread_join(threads[i], NULL);
    }

    printf("Expected: %d, Actual: %d\n",
           NUM_THREADS * INCREMENTS, counter);

    pthread_mutex_destroy(&counter_mutex);
    return 0;
}
```

### 常见错误与避免

| 错误 | 说明 | 避免方法 |
|------|------|---------|
| 忘记解锁 | 导致死锁 | 使用 `pthread_cleanup_push` 确保解锁 |
| 重复加锁 | 非递归锁会死锁 | 使用递归锁或检查逻辑 |
| 加锁顺序不一致 | 导致死锁 | 全局统一加锁顺序 |
| 在持有锁时调用可能阻塞的函数 | 降低并发性 | 缩小临界区范围 |

## 条件变量（Condition Variable）

### 基本概念

条件变量用于线程间等待某个条件成立，必须与互斥锁配合使用。

### 核心操作

```c
// 初始化
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;
int pthread_cond_init(pthread_cond_t *cond,
                      const pthread_condattr_t *attr);

// 等待条件（自动释放锁，被唤醒后重新获取锁）
int pthread_cond_wait(pthread_cond_t *cond,
                      pthread_mutex_t *mutex);

// 限时等待
int pthread_cond_timedwait(pthread_cond_t *cond,
                           pthread_mutex_t *mutex,
                           const struct timespec *abstime);

// 唤醒一个等待线程
int pthread_cond_signal(pthread_cond_t *cond);

// 唤醒所有等待线程
int pthread_cond_broadcast(pthread_cond_t *cond);

// 销毁
int pthread_cond_destroy(pthread_cond_t *cond);
```

### 使用模式

```c
// 等待方
pthread_mutex_lock(&mutex);
while (!condition) {           // 必须用 while，防止虚假唤醒
    pthread_cond_wait(&cond, &mutex);  // 原子操作：解锁->等待->加锁
}
// 条件满足，处理数据
pthread_mutex_unlock(&mutex);

// 通知方
pthread_mutex_lock(&mutex);
condition = true;              // 修改条件
pthread_cond_signal(&cond);    // 唤醒等待线程
pthread_mutex_unlock(&mutex);
```

### 完整示例：生产者-消费者

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <pthread.h>

#define BUFFER_SIZE 10

static int buffer[BUFFER_SIZE];
static int count = 0;
static int produce_index = 0;
static int consume_index = 0;

static pthread_mutex_t buffer_mutex = PTHREAD_MUTEX_INITIALIZER;
static pthread_cond_t not_full = PTHREAD_COND_INITIALIZER;
static pthread_cond_t not_empty = PTHREAD_COND_INITIALIZER;

void *producer(void *arg)
{
    int item = 0;
    while (1) {
        pthread_mutex_lock(&buffer_mutex);

        while (count == BUFFER_SIZE) {
            pthread_cond_wait(&not_full, &buffer_mutex);
        }

        buffer[produce_index] = item++;
        printf("Produced: %d (count=%d)\n", item - 1, count + 1);
        produce_index = (produce_index + 1) % BUFFER_SIZE;
        count++;

        pthread_cond_signal(&not_empty);
        pthread_mutex_unlock(&buffer_mutex);

        usleep(100000);  // 模拟生产时间
    }
    return NULL;
}

void *consumer(void *arg)
{
    while (1) {
        pthread_mutex_lock(&buffer_mutex);

        while (count == 0) {
            pthread_cond_wait(&not_empty, &buffer_mutex);
        }

        int item = buffer[consume_index];
        printf("Consumed: %d (count=%d)\n", item, count - 1);
        consume_index = (consume_index + 1) % BUFFER_SIZE;
        count--;

        pthread_cond_signal(&not_full);
        pthread_mutex_unlock(&buffer_mutex);

        usleep(200000);  // 模拟消费时间
    }
    return NULL;
}

int main(void)
{
    pthread_t prod, cons;

    pthread_create(&prod, NULL, producer, NULL);
    pthread_create(&cons, NULL, consumer, NULL);

    pthread_join(prod, NULL);
    pthread_join(cons, NULL);

    return 0;
}
```

### 常见错误

| 错误 | 说明 | 正确做法 |
|------|------|---------|
| 用 if 代替 while | 虚假唤醒导致条件不满足时继续执行 | 始终用 `while (!condition)` |
| 忘记持有锁就调用 signal | 可能导致唤醒丢失 | 在持有互斥锁时调用 signal |
| 使用 signal 代替 broadcast | 多个等待线程时只唤醒一个 | 根据场景选择 signal/broadcast |

## 读写锁（RWLock）

### 基本概念

读写锁适用于读多写少的场景：
- **读锁**：共享，多个读线程可同时持有
- **写锁**：排他，写线程独占访问

### 核心操作

```c
// 初始化
pthread_rwlock_t rwlock = PTHREAD_RWLOCK_INITIALIZER;
int pthread_rwlock_init(pthread_rwlock_t *rwlock,
                        const pthread_rwlockattr_t *attr);

// 读锁定
int pthread_rwlock_rdlock(pthread_rwlock_t *rwlock);
int pthread_rwlock_tryrdlock(pthread_rwlock_t *rwlock);

// 写锁定
int pthread_rwlock_wrlock(pthread_rwlock_t *rwlock);
int pthread_rwlock_trywrlock(pthread_rwlock_t *rwlock);

// 解锁
int pthread_rwlock_unlock(pthread_rwlock_t *rwlock);

// 销毁
int pthread_rwlock_destroy(pthread_rwlock_t *rwlock);
```

### 完整示例：缓存实现

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>

#define CACHE_SIZE 100

typedef struct {
    int key;
    char value[256];
    int valid;
} CacheEntry;

static CacheEntry cache[CACHE_SIZE];
static pthread_rwlock_t cache_lock = PTHREAD_RWLOCK_INITIALIZER;

const char *cache_read(int key)
{
    pthread_rwlock_rdlock(&cache_lock);

    for (int i = 0; i < CACHE_SIZE; i++) {
        if (cache[i].valid && cache[i].key == key) {
            const char *result = cache[i].value;
            pthread_rwlock_unlock(&cache_lock);
            return result;
        }
    }

    pthread_rwlock_unlock(&cache_lock);
    return NULL;
}

void cache_write(int key, const char *value)
{
    pthread_rwlock_wrlock(&cache_lock);

    for (int i = 0; i < CACHE_SIZE; i++) {
        if (!cache[i].valid) {
            cache[i].key = key;
            strncpy(cache[i].value, value, sizeof(cache[i].value) - 1);
            cache[i].valid = 1;
            break;
        }
    }

    pthread_rwlock_unlock(&cache_lock);
}

int main(void)
{
    // 初始化缓存
    memset(cache, 0, sizeof(cache));

    // 示例：写操作
    cache_write(1, "Hello");
    cache_write(2, "World");

    // 示例：读操作
    const char *val = cache_read(1);
    if (val) {
        printf("Cache hit: %s\n", val);
    }

    pthread_rwlock_destroy(&cache_lock);
    return 0;
}
```

## 屏障（Barrier）

### 基本概念

屏障用于同步多个线程，使它们在某一点等待，直到所有线程都到达后才一起继续。

### 核心操作

```c
// 初始化（count 为需要等待的线程数）
int pthread_barrier_init(pthread_barrier_t *barrier,
                         const pthread_barrierattr_t *attr,
                         unsigned int count);

// 等待屏障
int pthread_barrier_wait(pthread_barrier_t *barrier);
// 返回值：PTHREAD_BARRIER_SERIAL_THREAD（最后一个到达的线程）或 0

// 销毁
int pthread_barrier_destroy(pthread_barrier_t *barrier);
```

### 完整示例：并行计算

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

#define NUM_THREADS 4
#define DATA_SIZE 1000000

static double data[DATA_SIZE];
static double partial_sums[NUM_THREADS];
static pthread_barrier_t barrier;

void *compute_partial(void *arg)
{
    int id = *(int *)arg;
    int chunk = DATA_SIZE / NUM_THREADS;
    int start = id * chunk;
    int end = (id == NUM_THREADS - 1) ? DATA_SIZE : start + chunk;

    // 阶段1：计算局部和
    partial_sums[id] = 0;
    for (int i = start; i < end; i++) {
        partial_sums[id] += data[i];
    }
    printf("Thread %d: partial sum = %.2f\n", id, partial_sums[id]);

    // 等待所有线程完成阶段1
    pthread_barrier_wait(&barrier);

    // 阶段2：线程0计算总和
    if (id == 0) {
        double total = 0;
        for (int i = 0; i < NUM_THREADS; i++) {
            total += partial_sums[i];
        }
        printf("Total sum = %.2f\n", total);
    }

    return NULL;
}

int main(void)
{
    pthread_t threads[NUM_THREADS];
    int thread_ids[NUM_THREADS];

    // 初始化数据
    for (int i = 0; i < DATA_SIZE; i++) {
        data[i] = 1.0;
    }

    // 初始化屏障
    pthread_barrier_init(&barrier, NULL, NUM_THREADS);

    // 创建线程
    for (int i = 0; i < NUM_THREADS; i++) {
        thread_ids[i] = i;
        pthread_create(&threads[i], NULL, compute_partial, &thread_ids[i]);
    }

    // 等待所有线程
    for (int i = 0; i < NUM_THREADS; i++) {
        pthread_join(threads[i], NULL);
    }

    pthread_barrier_destroy(&barrier);
    return 0;
}
```

## 线程局部存储（TLS）

### 基本概念

TLS 允许每个线程拥有独立的数据副本，避免全局变量的竞争。

### 核心操作

```c
// 创建键（destructor 在线程退出时自动调用，可为 NULL）
int pthread_key_create(pthread_key_t *key, void (*destructor)(void *));

// 删除键
int pthread_key_delete(pthread_key_t key);

// 设置线程特定值
int pthread_setspecific(pthread_key_t key, const void *value);

// 获取线程特定值
void *pthread_getspecific(pthread_key_t key);
```

### 完整示例：线程安全的日志

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>

static pthread_key_t log_buffer_key;
static pthread_once_t log_once = PTHREAD_ONCE_INIT;

void destroy_log_buffer(void *buf)
{
    free(buf);
}

void init_log_key(void)
{
    pthread_key_create(&log_buffer_key, destroy_log_buffer);
}

char *get_log_buffer(void)
{
    pthread_once(&log_once, init_log_key);

    char *buf = pthread_getspecific(log_buffer_key);
    if (buf == NULL) {
        buf = malloc(1024);
        pthread_setspecific(log_buffer_key, buf);
    }
    return buf;
}

void *worker(void *arg)
{
    int id = *(int *)arg;
    char *buf = get_log_buffer();

    snprintf(buf, 1024, "Thread %d log message", id);
    printf("%s\n", buf);

    return NULL;
}

int main(void)
{
    pthread_t threads[3];
    int ids[3] = {1, 2, 3};

    for (int i = 0; i < 3; i++) {
        pthread_create(&threads[i], NULL, worker, &ids[i]);
    }

    for (int i = 0; i < 3; i++) {
        pthread_join(threads[i], NULL);
    }

    pthread_key_delete(log_buffer_key);
    return 0;
}
```

## 线程取消机制详解

### 取消状态与类型

```c
// 设置取消状态
int pthread_setcancelstate(int state, int *oldstate);
// state: PTHREAD_CANCEL_ENABLE（默认）或 PTHREAD_CANCEL_DISABLE

// 设置取消类型
int pthread_setcanceltype(int type, int *oldtype);
// type: PTHREAD_CANCEL_DEFERRED（默认，延迟取消）或 PTHREAD_CANCEL_ASYNCHRONOUS（异步取消）
```

### 取消点（Cancellation Points）

延迟取消模式下，线程只在以下函数调用时检查取消请求：

- 线程等待：`pthread_join`, `pthread_cond_wait`, `pthread_barrier_wait`
- I/O 操作：`read`, `write`, `open`, `close`, `recv`, `send`
- 睡眠：`sleep`, `usleep`, `nanosleep`
- 显式取消点：`pthread_testcancel()`

### 清理处理程序

```c
// 注册清理函数（栈结构，后注册的先执行）
void pthread_cleanup_push(void (*routine)(void *), void *arg);

// 弹出清理函数（execute: 是否执行）
void pthread_cleanup_pop(int execute);
```

**示例**：确保资源释放

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

void cleanup_handler(void *arg)
{
    FILE *fp = (FILE *)arg;
    printf("Cleanup: closing file\n");
    fclose(fp);
}

void *file_processor(void *arg)
{
    const char *filename = (const char *)arg;
    FILE *fp = fopen(filename, "r");
    if (fp == NULL) {
        pthread_exit((void *)-1);
    }

    // 注册清理函数
    pthread_cleanup_push(cleanup_handler, fp);

    // 模拟长时间处理
    for (int i = 0; i < 10; i++) {
        printf("Processing line %d...\n", i);
        sleep(1);
        pthread_testcancel();  // 显式取消点
    }

    // 弹出清理函数（execute=1 表示执行）
    pthread_cleanup_pop(1);
    return (void *)0;
}

int main(void)
{
    pthread_t tid;

    pthread_create(&tid, NULL, file_processor, "data.txt");

    sleep(3);
    printf("Main: cancelling thread...\n");
    pthread_cancel(tid);

    pthread_join(tid, NULL);
    printf("Main: thread finished\n");

    return 0;
}
```

> **注意**：`pthread_cleanup_push` 和 `pthread_cleanup_pop` 必须成对出现，且在同一作用域内。
