# 获取可变参数宏的参数数量

参考：https://blog.csdn.net/10km/article/details/80760533

```c
// 计算 __VA_ARGS__ 参数个数, 最大支持5个参数
#define FL_INTERNAL_ARG_COUNT_PRIVATE(_0, _1, _2, _3, _4, _5, N, ...) N
#define FL_ARG_COUNT(...) FL_INTERNAL_ARG_COUNT_PRIVATE(0, ##__VA_ARGS__, 5, 4,  3,  2,  1,  0)

void handle(u32 val_num, ...)
{
    printf("val_num param:%u\n", val_num);
}
#define VAR_DEBUG(level, file_code, X, format...)   \
    do {                                            \
        handle(FL_ARG_COUNT(S, ##format)-1, ##format); \
    } while (0)
```

注意：`FL_ARG_COUNT(S, ##format)`中的第一个参数的作用是解决预处理令牌无效：

```
error: expected ';' before '(' token
```
