# __interrupt关键字的作用

在嵌入式系统中，__interrupt 是一个关键字，用于标识一个中断服务例程（ISR, Interrupt Service Routine）。这个关键字的作用和意义如下：

⑴中断服务例程 (ISR)

-   定义：ISR 是处理特定中断事件的函数，当特定的硬件事件（如定时器溢出、外部信号变化等）发生时，控制权将转移到相应的 ISR。
-   作用：当中断被触发时，微控制器暂停当前执行的任务，并立即跳转到对应的 ISR 来处理该事件。

⑵ 确保正确性：使用 `__interrupt` 关键字可以告诉编译器这是一个特殊类型的函数，它会影响函数调用的方式，以确保中断处理过程中的状态保存和恢复是安全和有效的。

⑶编译器特性

-   生成合适的代码：`__interrupt` 关键字指示编译器为该函数生成适当的代码，包括保存必要的寄存器状态以及在 ISR 执行后恢复这些状态。
-   禁止某些操作：在某些环境下，该关键字可能也用于禁止某些优化，以确保 ISR 的执行不被干扰。

⑷ 中断优先级和嵌套支持：一些编译器支持使用`__interrupt`来帮助管理中断优先级及允许中断嵌套，这对实时系统至关重要。

示例代码：

```c
#include <avr/interrupt.h>

volatile int count = 0;

void __interrupt my_isr() {
    count++; // 每次触发中断，计数加一
}

int main() {
    sei(); // 全局使能中断
    while(1) {
        // 主循环
    }
}
```

在以上示例中：my_isr 被标记为一个中断服务例程，每当对应的硬件事件触发时，将执行该函数。在这里，我们简单地增加了一个计数变量。
